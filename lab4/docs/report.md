# Отчет по лабораторной работе №4 (n8n)
**Студент:** Тачгулиев

## 1. Краткое описание выполненного
Развернута платформа автоматизации n8n и in-memory СУБД Redis через Docker. Реализованы базовые workflow с использованием нод Manual Trigger, Code, Set, If, HTTP Request и Schedule Trigger. Настроена интеграция с Redis для CRUD-операций с ключами.

## 2. Способ установки и версии
* Установка: Docker Desktop (проброс портов 5678 для n8n и 6379 для Redis).
* Версия n8n: 1.15.0 (или latest на момент установки).
* Версия Node.js: встроенная в официальный образ n8nio/n8n.

## 3. Освоенные ноды
* **Manual Trigger:** ручной запуск потоков.
* **Set (Edit Fields):** создание и изменение структуры payload, генерация timestamp.
* **Code:** написание кастомной логики на JavaScript (циклы, массивы, генерация объектов).
* **If:** настройка ветвления (true/false) на основе математических операций.
* **HTTP Request:** GET-запросы к публичным API (генерация шуток).
* **Schedule Trigger:** запуск задач по расписанию (cron).
* **Redis:** операции Set, Get, Delete по ключам.
