# Бизнес-процесс: Онлайн-заказ еды в ресторане с доставкой

### Участники (роли):
1. **Клиент** — выбирает блюда, оплачивает и принимает заказ.
2. **Мобильное приложение** — интерфейс системы, проверяет данные.
3. **Платежный шлюз (Банк)** — проводит транзакцию оплаты.
4. **Ресторан (Кухня)** — готовит и упаковывает еду.
5. **Курьер** — забирает блюда и доставляет клиенту.

### Описание процесса:
1. Клиент формирует корзину выбранных блюд в приложении и нажимает кнопку оформления заказа.
2. Система приложения отправляет запрос на сервер ресторана для проверки наличия позиций.
3. **Ветвление 1:** Если хотя бы одного блюда нет в наличии, заказ отклоняется с уведомлением клиента; если все блюда доступны, система переводит клиента на экран оплаты.
4. Клиент выбирает способ оплаты и подтверждает списание денежных средств.
5. **Ветвление 2:** При ошибке списания (недостаточно средств) система предлагает сменить карту; при успешной оплате заказ моментально передается на кухню ресторана.
6. **Параллельные действия:** Пока повара ресторана готовят и упаковывают блюда, алгоритм системы одновременно ищет и назначает ближайшего свободного курьера.
7. Назначенный курьер принимает заявку и выдвигается в ресторан.
8. Персонал ресторана передает готовый упакованный заказ курьеру.
9. Курьер привозит заказ по адресу клиента.
10. Клиент забирает заказ и подтверждает успешную доставку в приложении, завершая процесс.
