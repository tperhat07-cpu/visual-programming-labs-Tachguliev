## 3. Сравнение версионирования (git diff)
Когда я добавил новый шаг («SMS-уведомление») в схему BPMN, я проверил разницу файлов через консоль:
* В файле **.bpmn** Git сразу показал зеленым цветом добавленный кусок XML-кода с названием блока и новые стрелки. То есть текстовые схемы версионируются идеально — видно каждую строчку.
* Для файла **.png** Git просто написал `Binary files differ`. Внутри картинки Git изменения отследить не может, он видит её целиком как один большой файл.
